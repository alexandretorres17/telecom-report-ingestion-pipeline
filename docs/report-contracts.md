# Public report contracts

The original input reports were generated by operational systems and are not included. The code retains the historical transformation functions and column mappings because they demonstrate the real integration complexity.

The orchestrator recognizes these logical report families:

| Family | Historical purpose |
|---|---|
| `NETWORKS` | Multi-technology site, cell, software and topology inventory |
| `EXTERNALS` | Inter-technology neighbour and external-cell relationships |
| `HCMD` | Operational command-log parsing and classification |
| `PKI` | Certificate inventory and expiration tracking |
| `WEEKPLAN` | Approved rota/availability hand-off to another workflow |
| Other names | Generic dataframe-to-table ingestion |

Subjects followed the logical form `[Report][REGION][TYPE][YYYY-MM-DD]`. All regions, addresses and examples in this repository are fictional.
